# Кейс-задача № 1

## Условие

Дан одномерный массив `A` размерности `N`. Требуется найти сумму отрицательных элементов, расположенных между максимальным и минимальным элементами массива.

## Алгоритм

1. Считать размер массива и его элементы.
2. Найти минимальный и максимальный элементы.
3. Определить их индексы.
4. Определить левую и правую границы независимо от порядка расположения min и max.
5. Просмотреть элементы строго между этими границами.
6. Сложить только отрицательные значения.

Если минимальное или максимальное значение встречается несколько раз, программа использует первое вхождение.

## Пример

Ввод:

```text
Введите размер массива N: 7
Введите 7 чисел через пробел: 7 -3 -5 12 -2 -8 1
```

Между максимальным элементом `12` и минимальным элементом `-8` находится `-2`, поэтому результат равен `-2`.

## Запуск

```bash
python main.py
```
