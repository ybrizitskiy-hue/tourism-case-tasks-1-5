# Анализ информационных систем, построенных по WEB-архитектуре

## 1. Общая характеристика WEB-архитектуры

WEB-приложение представляет собой информационную систему, в которой пользователь работает через браузер, а основная обработка данных выполняется на сервере. Типовая схема включает клиентский уровень, WEB-сервер, прикладную логику и систему управления базами данных.

Клиент отправляет HTTP- или HTTPS-запросы через браузер. WEB-сервер принимает запрос и передает его приложению. При необходимости приложение обращается к базе данных, выполняет бизнес-операции и возвращает пользователю сформированную HTML-страницу или данные в другом формате.

Для организации такой системы не требуется устанавливать полноценную программу на каждый рабочий компьютер. Пользователю обычно достаточно современного браузера и доступа к сети. Обновление прикладной части выполняется централизованно на сервере.

Основными преимуществами WEB-архитектуры являются:

- централизованное хранение и обработка данных;
- доступ с различных рабочих мест;
- отсутствие необходимости устанавливать клиентское приложение на каждый компьютер;
- упрощенное обновление программного обеспечения;
- возможность разграничивать доступ пользователей;
- удобство интеграции с другими информационными системами через сетевые интерфейсы;
- возможность размещения системы как внутри локальной сети предприятия, так и во внешней инфраструктуре.

К ограничениям относятся зависимость от сети, необходимость защиты WEB-сервера и базы данных, а также необходимость учитывать одновременную работу нескольких пользователей.

## 2. Примеры существующих систем

### 2.1 Salesforce Sales Cloud

Salesforce Sales Cloud относится к классу CRM-систем. WEB-интерфейс позволяет работать с клиентами, контактами, потенциальными сделками и продажами. В системе используются сущности Leads, Accounts, Contacts и Opportunities. Пользователь может вести карточки клиентов, фиксировать этапы сделки, хранить историю взаимодействия и получать сводную информацию по продажам.

В компании такая система может применяться отделом продаж и руководителями подразделений. Менеджеры ведут клиентскую базу и сделки, а руководство получает единое представление о текущей работе отдела. WEB-архитектура удобна для организаций, в которых сотрудники работают из разных офисов или удаленно.

### 2.2 Microsoft Dynamics 365 Sales

Microsoft Dynamics 365 Sales является WEB-ориентированной CRM-системой для управления продажами. Она позволяет вести сведения об организациях и контактах, обрабатывать потенциальных клиентов, управлять возможностями продаж, заказами и связанными процессами.

Система может использоваться в компании как единое рабочее пространство отдела продаж. Отдельным преимуществом для организаций, использующих инфраструктуру Microsoft, является возможность интеграции с другими корпоративными продуктами и средствами отчетности.

Практический вариант использования: регистрация нового обращения, назначение ответственного менеджера, перевод обращения в сделку, сопровождение продажи и последующий анализ результатов работы.

### 2.3 Bitrix24 CRM

Bitrix24 содержит WEB-модуль CRM, инструменты работы с контактами и сделками, управление задачами, коммуникации и отчетность. Система может использоваться через браузер, поэтому подходит как для офиса, так и для распределенной команды.

Для небольшой или средней компании Bitrix24 может применяться сразу в нескольких направлениях: хранение клиентской базы, контроль этапов продаж, постановка задач сотрудникам, фиксация обращений и контроль выполнения работ.

Для туристической компании подобная система может использоваться для регистрации обращений клиентов, хранения контактной информации, контроля заявок на туры и напоминаний менеджерам о последующих действиях.

### 2.4 SAP Business One Web Client

SAP Business One относится к классу ERP-систем для управления различными бизнес-процессами организации. Для SAP Business One существует Web Client, предоставляющий доступ к основным бизнес-функциям через браузер. В официальной документации указано, что Web Client может работать с SAP Business One на базе MS SQL Server или SAP HANA.

В компании такая система может использоваться не только для взаимодействия с клиентами, но и для более широкого учета: продажи, закупки, справочники деловых партнеров, документы и связанные хозяйственные операции. Такой вариант подходит организациям, которым требуется комплексная информационная система, а не только учет продаж.

## 3. Сравнение вариантов

| Система | Основное назначение | WEB-доступ | Возможный вариант использования |
| --- | --- | --- | --- |
| Salesforce Sales Cloud | CRM, управление продажами | Да | Клиенты, контакты, сделки, работа отдела продаж |
| Microsoft Dynamics 365 Sales | CRM, управление продажами | Да | Продажи, заказы, работа менеджеров, корпоративная интеграция |
| Bitrix24 CRM | CRM и совместная работа | Да | Клиентская база, сделки, задачи, работа небольшой или средней компании |
| SAP Business One Web Client | ERP | Да | Комплексный учет продаж и других бизнес-процессов |

Рассмотренные системы показывают общий принцип современных WEB-приложений: пользователь работает через браузер, а данные и бизнес-логика находятся на серверной стороне. Различия заключаются прежде всего в масштабе системы и наборе решаемых задач.

Для небольшой туристической компании полноценная ERP-система может оказаться избыточной, если требуется только регистрация клиентов и туров. В таком случае можно применять CRM или разработать специализированное WEB-приложение, содержащее только необходимые функции.

## 4. Предлагаемый вариант для туристической компании

В рамках практической части разработано небольшое WEB-приложение «Учет заказов туристической компании».

Приложение решает следующие задачи:

1. хранение справочника стран;
2. хранение справочника отелей;
3. хранение типов туров;
4. хранение клиентов;
5. оформление нового заказа;
6. просмотр списка заказов.

Архитектура приложения:

```text
Браузер пользователя
        |
        | HTTP
        v
Microsoft IIS
        |
        | ISAPI
        v
Delphi WebBroker-приложение
        |
        | FireDAC
        v
Microsoft SQL Server
```

IIS выполняет роль WEB-сервера. Приложение создается в Delphi 10.2 на базе WebBroker и компилируется в ISAPI DLL. Для доступа к MS SQL Server применяется FireDAC.

Разделение на WEB-сервер, приложение и СУБД позволяет централизовать работу с данными. Несколько сотрудников могут работать с одной базой через браузер. При дальнейшем развитии проекта можно добавить авторизацию, изменение статусов заказов, удаление и редактирование записей, поиск, отчеты и разграничение прав доступа.

## 5. Вывод

WEB-архитектура широко применяется в CRM, ERP и других корпоративных информационных системах. Ее основные преимущества для компании связаны с централизованной работой, доступом через браузер и упрощением сопровождения рабочих мест.

Для учебного проекта выбрана трехуровневая схема: браузер — IIS/Delphi WebBroker — MS SQL Server. Она соответствует требованиям задания и демонстрирует основные принципы WEB-приложения: обработку HTTP-запросов, серверную бизнес-логику и работу с реляционной базой данных.
