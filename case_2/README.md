# Кейс-задача № 2

## Задание

Написать тестовую программу, которая демонстрирует работу методов базового и производного классов.

## Реализация

В программе используется предметная область «Туризм».

Базовый класс `Tour` хранит общую информацию о туре и содержит методы:

- `get_description()` — вывод основных сведений о туре;
- `calculate_total()` — расчет общей стоимости для нескольких туристов.

Производный класс `BeachTour` наследуется от `Tour` и:

- добавляет сведения об отеле и расстоянии до пляжа;
- переопределяет `get_description()`;
- добавляет собственный метод `beach_info()`.

Файл `main.py` создает объекты обоих классов и демонстрирует наследование, переопределение метода и полиморфный вызов.

## Запуск

```bash
python main.py
```
