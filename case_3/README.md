# Кейс-задача № 3 — база данных «Туризм»

## Структура базы данных

Скрипт рассчитан на MySQL 8.0.16 или новее, где ограничения `CHECK` проверяются сервером.

Создано пять таблиц:

1. `countries` — справочник стран;
2. `hotels` — справочник отелей;
3. `tour_types` — справочник типов туров;
4. `clients` — справочник клиентов;
5. `tour_orders` — таблица переменной информации с заказами.

Для каждой таблицы определен первичный ключ. Таблица `tour_orders` связана внешними ключами со справочниками клиентов, отелей и типов туров. Справочник отелей дополнительно связан со справочником стран.

## Связи

```text
countries 1 --- N hotels
                   |
                   | 1
                   |
                   N
               tour_orders N --- 1 clients
                   |
                   N
                   |
                   1
              tour_types
```

## Создание базы в MySQL Workbench

1. Открыть MySQL Workbench.
2. Подключиться к серверу MySQL.
3. Открыть файл `tourism_mysql.sql`.
4. Выполнить весь скрипт.
5. В списке схем появится база `tourism`.

Скрипт удаляет существующую базу `tourism` и создает ее заново. Он содержит таблицы, первичные и внешние ключи, индекс по дате заказа, тестовые записи и пример итогового запроса.
