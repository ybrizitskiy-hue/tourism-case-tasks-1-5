# Кейс-задачи по программированию и базам данных

Репозиторий содержит решения пяти кейс-задач.

## Содержание

- `case_1` - обработка одномерного массива на Python.
- `case_2` - демонстрация базового и производного классов на Python.
- `case_3` - база данных «Туризм» в MySQL.
- `case_4` - WEB-приложение «Учет заказов туристической компании» для Delphi 10.2, IIS и MS SQL Server, а также анализ существующих WEB-систем.
- `case_5` - аналитический обзор кейс-задачи № 4 в формате DOCX.

## Требования

### Кейсы 1–2

- Python 3.10 или новее.

### Кейс 3

- MySQL 8.0.16 или новее (для проверки ограничений `CHECK`);
- MySQL Workbench или другой клиент для выполнения SQL.

Скрипт `case_3/tourism_mysql.sql` удаляет существующую базу `tourism` и создает ее заново с тестовыми данными.

### Кейс 4

- Delphi 10.2 Tokyo;
- IIS с поддержкой ISAPI;
- Microsoft SQL Server;
- FireDAC с драйвером MSSQL.

Подробная инструкция находится в `case_4/README.md`.

### Кейс 5

Аналитический обзор выполненной кейс-задачи № 4 находится в файле:

`case_5/Кейс-задача_5_Аналитический_обзор.docx`
